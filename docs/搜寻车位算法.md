# 搜寻车位算法

## 1. 目标

通过超声波侧向测距与小车匀速前进时间，判断目标侧是否存在可停车位。

## 2. 已知参数

以下搜索速度参数基于 `2026-03-19` 实车测试结果更新。
当前搜索参数仍以“后往前寻位（R2F search + reverse park）”为基准记录。
“前往后寻位（F2R search + forward park）”目前已开始单独精调停车阶段参数，现已单独修正第一段、第一次自转和第二次自转。

| 参数 | 符号 | 数值 |
|---|---|---|
| 小车长度 | `L_car` | `31 cm` |
| 小车宽度 | `W_car` | `17 cm` |
| 侧向冗余 | `W_margin` | `5 cm` |
| 车位长度冗余 | `L_margin` | `6 cm` |
| 搜索车速（10%速度） | `v` | `18.46 cm/s` |
| 传感器到车体侧边偏移 | `d_offset` | `9 cm` |

由此得到：

- 侧向可进入阈值：`W_th = W_car + W_margin = 22 cm`
- 最小车位长度阈值：`L_th = L_car + L_margin = 37 cm`

## 3. 测距修正（左右侧一致）

超声波模块位于小车尾部中间，测距相对车体侧边存在固定偏移 `9 cm`，因此：

`d_side = d_raw - d_offset = d_raw - 9`

其中：

- `d_raw`：超声波原始测距值（cm）
- `d_side`：小车侧边到障碍物真实距离（cm）

示例：

- 若向右测得 `d_raw = 20 cm`，则右侧真实间距 `d_side = 20 - 9 = 11 cm`
- 左侧同理，仍减去 `9 cm`

## 4. 车位判定规则

### 4.1 开始计时条件（进入“开口区”）

当目标侧满足：

`d_side > 22 cm`

即开始计时。

等价原始测距条件：

`d_raw > 31 cm`

### 4.2 结束计时条件（离开“开口区”）

当目标侧满足：

`d_side <= 22 cm`

即结束计时，并计算该开口持续时间 `t_open`。

### 4.3 长度合格条件

利用匀速关系：

`L_slot = v * t_open`

合格条件：

`L_slot >= 37 cm`

当前代码中实际采用等价的时间阈值写法：

`t_open >= 37 / 18.46 ≈ 2.004 s`

## 5. 超声需要连续检测的最短时间

根据长度阈值：

`t_min = L_th / v = 37 / 18.46 ≈ 2.004 s`

工程判定建议：

`t_open >= 2.004 s` 视为存在可停车位。

## 6. 伪代码

```c
const float V_CM_S = 18.46f;
const float D_OFFSET_CM = 9.0f;
const float WIDTH_TH_CM = 22.0f;
const float TIME_TH_S = 37.0f / 18.46f;

bool in_open = false;
float t_start = 0.0f;

while (searching) {
    float d_raw = read_ultrasonic_cm();
    float d_side = d_raw - D_OFFSET_CM;

    if (d_side < 0.0f) {
        d_side = 0.0f;
    }

    if (d_side > WIDTH_TH_CM) {
        if (!in_open) {
            t_start = now_seconds();
            in_open = true;
        }
    } else { // d_side <= WIDTH_TH_CM
        if (in_open) {
            float t_open = now_seconds() - t_start;
            in_open = false;

            if (t_open >= TIME_TH_S) {
                // 找到可停车位
                slot_found();
                break;
            }
            // 长度不足，继续搜索
        }
    }
}
```

## 7. 测试用例

1. `d_raw = 20 cm`
   `d_side = 11 cm`，不进入计时。
2. `d_raw = 32 cm` 持续 `2.30 s`
   `d_side = 23 cm`，满足时间阈值，判定可停车位。
3. `d_raw = 32 cm` 持续 `2.00 s`
   `d_side = 23 cm`，时间不足，判定不可停车位。
4. 左侧检测同样使用 `d_side = d_raw - 9`
   与右侧判定逻辑一致。
5. 边界值 `d_raw = 31 cm`（即 `d_side = 22 cm`）
   由于规则是严格大于（`>`），不开始计时。

## 8. 假设与默认值

- 搜索阶段速度稳定为 `18.46 cm/s`
- 偏移量 `9 cm` 对左右侧一致且固定
- 阈值比较采用严格大于：`d_side > 22 cm`
- 采用“时间阈值法”估算车位长度，不额外加入滤波与状态补偿
