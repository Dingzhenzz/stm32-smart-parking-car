# 搜寻车位算法

## 1. 目标

通过超声波侧向测距与小车匀速行驶时间，识别目标侧的停车开口，并区分侧方位车位和垂直车位。

## 2. 已知参数

以下参数与 `Core/Src/main.c` 中的宏保持一致，标定基准为 `2026-03-19` 实车测试。

| 参数 | 符号 | 数值 |
|---|---|---:|
| 小车长度 | `L_car` | 31 cm |
| 小车宽度 | `W_car` | 17 cm |
| 侧向冗余 | `W_margin` | 5 cm |
| 侧方位长度冗余 | `L_margin` | 6 cm |
| 搜索车速（10% 速度） | `v` | 18.46 cm/s |
| 传感器到车体侧边偏移 | `d_offset` | 9 cm |
| 垂直车位最小开口 | `W_open_min` | 22 cm |
| 垂直车位最小槽深 | `L_depth_min` | 40 cm |

由此得到：

- 侧向可进入阈值：`W_th = W_car + W_margin = 22 cm`
- 最小侧方位长度：`L_th = L_car + L_margin = 37 cm`
- 最小垂直开口：`W_open_min = W_car + 5 = 22 cm`
- 最小垂直槽深：`L_depth_min = 40 cm`

## 3. 测距修正

超声波模块位于小车尾部中间，测距相对车体侧边存在固定偏移 `9 cm`：

```c
d_side = d_raw - d_offset;   // d_offset = 9.0 cm
```

其中：

- `d_raw`：超声波原始测距值（cm）
- `d_side`：车体侧边到障碍物的净距（cm）

如果 `d_side` 小于 0，代码会把它钳位到 0：

```c
if (d_side < 0.0f) d_side = 0.0f;
```

左右侧使用同一套修正，不区分符号。

示例：

- 向右测得 `d_raw = 20 cm`，则 `d_side = 20 - 9 = 11 cm`
- 向左测得 `d_raw = 50 cm`，则 `d_side = 50 - 9 = 41 cm`

## 4. 车位判定规则

### 4.1 开始计时条件（进入开放区）

当目标侧满足：

```text
d_side > 22 cm
```

即开始计时。等价原始测距条件：

```text
d_raw > 31 cm
```

比较采用严格大于，因此 `d_side == 22 cm`（`d_raw == 31 cm`）不进入开放区。

### 4.2 结束计时条件（离开开放区）

当目标侧满足：

```text
d_side <= 22 cm
```

即结束计时，并计算该开口的持续时间和长度：

```text
t_open = now - t_start
L_open = v * t_open = 18.46 * t_open
L_depth = 开放区内的最大 d_side
```

其中：

- `L_open`：沿行驶方向估算的开口长度
- `L_depth`：开口内的最大侧向净距，作为车位深度

在开放区持续期间，代码会持续更新 `L_depth`，取所有采样值中的最大值。

### 4.3 侧方位车位条件

利用匀速关系估算车位长度：

```text
L_slot = L_open = 18.46 * t_open
```

合格条件：

```text
L_open >= 37 cm
```

当前代码中采用等价的时间阈值写法：

```text
t_open >= 37 / 18.46 ≈ 2.004 s
```

### 4.4 垂直车位条件

如果开口不满足侧方位长度条件，再判断垂直车位：

```text
L_open >= 22 cm  且  L_depth >= 40 cm
```

即：

- 沿行驶方向的开口至少 22 cm
- 开口内的最大侧向深度至少 40 cm

这两个条件同时满足时，判定为垂直车位。

垂直车位的 22 cm 开口阈值对应的时间约为：

```text
t_open >= 22 / 18.46 ≈ 1.192 s
```

但代码实际比较的是 `L_open >= 22 cm`，不是单独的时间阈值。

### 4.5 类型优先级

同一开放区可能同时满足两类条件。代码先判断侧方位，再判断垂直：

1. 若 `t_open >= 2.004 s`（`L_open >= 37 cm`）：判为侧方位车位
2. 否则若 `L_open >= 22 cm` 且 `L_depth >= 40 cm`：判为垂直车位
3. 否则继续搜索

因此，垂直车位只在“开口长度未达到 37 cm”时才会被采用；当开口长度达到 37 cm 时，优先按侧方位处理。

## 5. 代码中的变量含义

| 变量 | 含义 |
|---|---|
| `g_in_open_region` | 当前是否处于开放区 |
| `g_open_start_tick_ms` | 开放区开始时刻 |
| `g_open_region_max_side_cm` | 开放区内的最大侧向净距 |
| `g_last_open_time_s` | 最近一次开放区持续时间 |
| `g_last_slot_length_cm` | `L_open`，沿行驶方向的开口长度 |
| `g_last_slot_depth_cm` | `L_depth`，车位深度 |
| `g_slot_stop_raw_cm` | 识别成功时的原始距离 |
| `g_slot_stop_side_cm` | 识别成功时的侧向净距 |
| `g_last_slot_type` | `SLOT_TYPE_PARALLEL` / `SLOT_TYPE_VERTICAL` |

注意：垂直模式下 `g_last_slot_length_cm` 表示**开口长度**，不是 40 cm 的槽深；槽深使用 `g_last_slot_depth_cm`。

## 6. 伪代码

```c
const float V_CM_S = 18.46f;
const float D_OFFSET_CM = 9.0f;
const float WIDTH_TH_CM = 22.0f;
const float TIME_TH_S = 37.0f / 18.46f;

bool in_open = false;
float t_start = 0.0f;
float max_side = 0.0f;

while (searching) {
    float d_raw = read_ultrasonic_cm();
    float d_side = d_raw - D_OFFSET_CM;

    if (d_side < 0.0f) {
        d_side = 0.0f;
    }

    if (d_side > WIDTH_TH_CM) {
        if (!in_open) {
            t_start = now_seconds();
            in_open = true;
            max_side = d_side;
        } else if (d_side > max_side) {
            max_side = d_side;
        }
    } else if (in_open) {
        float t_open = now_seconds() - t_start;
        float L_open = V_CM_S * t_open;
        float L_depth = max_side;

        in_open = false;

        if (t_open >= TIME_TH_S) {
            slot_type = SLOT_TYPE_PARALLEL;
            slot_found(slot_type, L_open, L_depth);
            break;
        }

        if ((L_open >= 22.0f) && (L_depth >= 40.0f)) {
            slot_type = SLOT_TYPE_VERTICAL;
            slot_found(slot_type, L_open, L_depth);
            break;
        }

        // 长度/深度不足，继续搜索
    }
}
```

## 7. 测试用例

1. `d_raw = 20 cm`
   - `d_side = 11 cm`，不进入开放区。
2. `d_raw = 32 cm` 持续 `2.30 s`
   - `d_side = 23 cm`，`L_open = 42.5 cm`，满足侧方位条件。
3. `d_raw = 32 cm` 持续 `2.00 s`，且 `L_depth < 40 cm`
   - `d_side = 23 cm`，`L_open = 36.9 cm`，不满足侧方位；深度也不满足垂直条件，继续搜索。
4. `d_raw = 50 cm` 持续 `2.00 s`，且 `L_depth >= 40 cm`
   - `L_open = 36.9 cm`，不满足侧方位，但满足垂直条件，判为垂直车位。
5. `d_raw = 50 cm` 持续 `1.30 s`
   - `d_side = 41 cm`，`L_open = 24.0 cm`，`L_depth = 41 cm`，判为垂直车位。
6. `d_raw = 50 cm` 持续 `2.20 s`
   - `L_open = 40.6 cm`，虽然深度也满足垂直条件，但侧方位优先，判为侧方位车位。
7. `d_raw = 31 cm`
   - `d_side = 22 cm`，由于比较是严格大于，不进入开放区。
8. 左侧和右侧使用同一套 `d_side = d_raw - 9` 修正，判定逻辑一致。

## 8. 假设与默认值

- 搜索阶段速度稳定为 `18.46 cm/s`（10% 占空比标定值）
- 偏移量 `9 cm` 对左右侧一致且固定
- 阈值比较采用严格大于：`d_side > 22 cm`
- 垂直车位开口阈值 `22 cm`、深度阈值 `40 cm`，比较采用大于等于
- 采用“时间 × 速度”估算开口长度，不额外加入滤波与状态补偿
- 采样周期约为 90 ms（60 ms 测距 + 30 ms 主循环），因此 `L_open` 存在约 ±1.7 cm 的采样量化误差
