# 自动泊车算法实施（对接 `bishe` 当前工程）

## 1. 文档范围

本文档说明当前 `bishe` 工程中“搜索车位 → 发现车位 → 人工确认 → 自动泊车”的实现方式，并与 [main.c](../firmware/Core/Src/main.c) 保持同步。

覆盖范围：

- 两种寻位/入位模式：后往前寻位 + 倒车入位、前往后寻位 + 前进入位
- 两种车位类型：侧方位车位、垂直车位
- 主状态机、泊车子状态机、搜索判定、参数和转向映射

说明：本文以当前代码为准；如果参数或流程有改动，请同步修改本文和 `Core/Src/main.c`。

---

## 2. 术语与模式

### 2.1 模式枚举

代码中的 `SearchMotion_t` 是历史命名，实际含义以界面标签为准：

| 枚举值 | 代码中的运动方向 | 界面标签 | 泊车方向 |
|---|---|---|---|
| `SEARCH_MOTION_FORWARD` | 四轮正转，小车前进 | 后往前搜位 + 倒车入位 | 倒车入位 |
| `SEARCH_MOTION_BACKWARD` | 四轮反转，小车后退 | 前往后搜位 + 前进入位 | 前进入位 |

`IsParkingBackward()` 的返回值：

- `SEARCH_MOTION_FORWARD` → `1`，走倒车入位参数
- `SEARCH_MOTION_BACKWARD` → `0`，走前进入位参数

### 2.2 车位方向

`g_search_dir` 取值为 `SEARCH_DIR_LEFT` 或 `SEARCH_DIR_RIGHT`，分别表示目标车位在车体左侧或右侧。

## 3. 主状态机

### 3.1 状态定义

```c
typedef enum
{
    CAR_MODE_IDLE = 0,
    CAR_MODE_WAIT_DIRECTION,
    CAR_MODE_SEARCHING_SLOT,
    CAR_MODE_WAIT_KEY1_CONFIRM,
    CAR_MODE_PARKING
} CarMode_t;
```

当前工程没有 `CAR_MODE_REVERSING`；所有泊车动作都在 `CAR_MODE_PARKING` 下由 `Parking_Update()` 推进。

### 3.2 按键行为

| 当前状态 | 按键 | 行为 |
|---|---|---|
| `CAR_MODE_IDLE` | `KEY_UP` | 选择“后往前 + 倒车入位”，进入 `WAIT_DIRECTION` |
| `CAR_MODE_IDLE` | `KEY1` | 选择“前往后 + 前进入位”，进入 `WAIT_DIRECTION` |
| `CAR_MODE_WAIT_DIRECTION` | `KEY_UP` / `KEY1` | 切换寻位/入位模式 |
| `CAR_MODE_WAIT_DIRECTION` | `KEY2` | 开始左侧搜索 |
| `CAR_MODE_WAIT_DIRECTION` | `KEY0` | 开始右侧搜索 |
| `CAR_MODE_SEARCHING_SLOT` | `KEY_UP` | 停车并返回 `WAIT_DIRECTION` |
| `CAR_MODE_WAIT_KEY1_CONFIRM` | `KEY1` | 调用 `Parking_Start()`，进入 `CAR_MODE_PARKING` |
| `CAR_MODE_PARKING` | `KEY_UP` | 调用 `Parking_Abort()`，停车并返回 `WAIT_DIRECTION` |

注意：等待确认阶段当前只响应 `KEY1`，没有单独的 `KEY_UP` 取消分支；如果识别后不想泊车，需要先确认进入泊车再按 `KEY_UP` 中止，或复位。

## 4. 搜索车位

### 4.1 测距与修正

`UpdateSlotSearch()` 每个搜索周期调用一次 `MeasureDistanceCm()`：

1. 触发 SR04，等待 60 ms
2. 读取距离，换算为 cm
3. 有效范围 2–400 cm
4. 计算侧向净距：

```c
d_side = d_raw - SLOT_SENSOR_OFFSET_CM;   // 9.0 cm
if (d_side < 0.0f) d_side = 0.0f;
```

### 4.2 开放区判定

- 当 `d_side > 22.0 cm` 时，认为进入开放区，记录开始时刻，并持续更新最大侧向距离。
- 当 `d_side <= 22.0 cm` 时，认为离开开放区，计算：

```c
t_open = (now_ms - start_ms) / 1000.0f;
L_open = 18.46f * t_open;                 // 沿行驶方向的开口长度
L_depth = max_side_cm;                    // 开放区内的最大侧向距离
```

其中：

- `L_open` 是沿行驶方向估算的开口长度，不是车位深度
- `L_depth` 是车体侧边到障碍物的最大净距，作为车位深度

### 4.3 车位类型判定

先判断侧方位，再判断垂直，侧方位优先：

```c
parallel_candidate = (t_open >= 2.004f);                       // L_open >= 37 cm
vertical_candidate = (L_open >= 22.0f) && (L_depth >= 40.0f);  // 开口 + 槽深
```

- 若 `parallel_candidate` 成立：`SLOT_TYPE_PARALLEL`
- 否则若 `vertical_candidate` 成立：`SLOT_TYPE_VERTICAL`
- 否则继续搜索

也就是说，垂直车位只在“不满足侧方位长度阈值”时才会被采用；当开口长度已经达到 37 cm 时，优先按侧方位处理。

### 4.4 识别后记录

识别成功后记录并停车：

- `g_last_open_time_s`：开放区持续时间
- `g_last_slot_length_cm`：`L_open`
- `g_last_slot_depth_cm`：`L_depth`
- `g_slot_stop_raw_cm`：停车时的原始超声距离
- `g_slot_stop_side_cm`：停车时的侧向净距
- `g_last_slot_type`：`SLOT_TYPE_PARALLEL` 或 `SLOT_TYPE_VERTICAL`

然后调用 `Motion_StopBrake()`，进入 `CAR_MODE_WAIT_KEY1_CONFIRM`。

## 5. 泊车子状态机

### 5.1 状态定义

```c
typedef enum
{
    PARK_STAGE_INIT = 0,
    PARK_STAGE_FIRST_STRAIGHT,
    PARK_STAGE_FIRST_TURN,
    PARK_STAGE_SECOND_STRAIGHT,
    PARK_STAGE_SECOND_TURN,
    PARK_STAGE_VERTICAL_ALIGN,
    PARK_STAGE_VERTICAL_TURN,
    PARK_STAGE_VERTICAL_REVERSE_IN,
    PARK_STAGE_DONE,
    PARK_STAGE_ABORT
} ParkingStage_t;
```

### 5.2 平行泊车流程

适用于 `SLOT_TYPE_PARALLEL`：

```text
FIRST_STRAIGHT → FIRST_TURN → SECOND_STRAIGHT → SECOND_TURN → DONE
```

- 第一段直行距离：

```c
d1 = L_open * (IsParkingBackward() ? 4.0f / 5.0f : 1.0f / 2.0f);
```

- 第二段直行距离：

```c
d2 = g_slot_stop_raw_cm * 1.1f;
```

- 第一次自转时间：倒车入位 `1301 ms`，前进入位 `1464 ms`
- 第二次自转时间：倒车入位 `1544 ms`，前进入位 `1563 ms`

### 5.3 垂直泊车流程

适用于 `SLOT_TYPE_VERTICAL`：

```text
VERTICAL_ALIGN → VERTICAL_TURN → VERTICAL_REVERSE_IN → DONE
```

- 对中距离：

```c
d1 = L_open * (IsParkingBackward() ? 9.0f / 10.0f : 3.0f / 4.0f);
if (d1 < 8.0f)  d1 = 8.0f;
if (d1 > L_open) d1 = L_open;
```

- 入位距离：

```c
d2 = L_depth - (IsParkingBackward() ? 6.0f : 18.0f);
if (!IsParkingBackward() && d2 > 40.0f) d2 = 40.0f;
```

如果 `d2 < CAR_LENGTH_CM / 2`，`Parking_Start()` 会直接中止，返回 `WAIT_DIRECTION`。

- 垂直自转时间：倒车入位 `1303 ms`，前进入位 `1765 ms`
- 垂直模式只有一次自转，没有第二次自转

### 5.4 位移积分

直行阶段使用时间积分估算位移：

```c
moved += V_MOVE_CM_S * dt_s;
```

- `V_MOVE_CM_S = 18.46f`
- `dt_s` 为本次 `Parking_Update()` 与上次调用之间的秒数
- 倒车阶段只有在“后向测距有效且未因障碍暂停”或“避障功能关闭”时才积分

## 7. 左右转向映射

### 7.1 平行泊车

| 模式 | 车位 | 第一次自转 | 第二次自转 |
|---|---|---|---|
| 倒车入位（R2F） | 左侧 | 右自转 | 左自转 |
| 倒车入位（R2F） | 右侧 | 左自转 | 右自转 |
| 前进入位（F2R） | 左侧 | 左自转 | 右自转 |
| 前进入位（F2R） | 右侧 | 右自转 | 左自转 |

### 7.2 垂直泊车

| 模式 | 车位 | 自转方向 |
|---|---|---|
| 倒车入位（R2F） | 左侧 | 右自转 |
| 倒车入位（R2F） | 右侧 | 左自转 |
| 前进入位（F2R） | 左侧 | 左自转 |
| 前进入位（F2R） | 右侧 | 右自转 |

垂直模式在自转完成后直接直线入位，不再执行第二次自转。

## 8. 防碰撞与蜂鸣器

### 8.1 防碰撞

说明：以下逻辑只在 `REVERSE_OBSTACLE_AVOID_ENABLE = 1` 时生效，当前默认关闭。

仅对“后退”阶段生效，自转阶段不做暂停控制：

- `d_rear < 5.0 cm`：立即 `Motion_StopBrake()`，置 `g_parking_paused_by_obstacle = 1`
- `d_rear > 5.0 cm`：恢复 `Motion_ParkBackward()`，置 `g_parking_paused_by_obstacle = 0`
- `d_rear == 5.0 cm`：保持当前状态

如果后向测距无效（`rear_ok == 0`）且避障开启，代码不会进入“停车”或“恢复”分支，电机会保持上一拍的命令；当前避障默认关闭，因此不影响默认配置。

### 8.2 蜂鸣器

说明：以下逻辑只在 `REVERSE_BEEP_ENABLE = 1` 时生效，当前默认关闭。

仅在后退阶段启用：

- 正常后退时周期性间断鸣叫
- `d_rear <= 12.0 cm` 时提高鸣叫频率
- 已触发防碰撞暂停时持续导通，作为紧急报警
- 自转、完成或中止时关闭蜂鸣器

## 9. 验收建议

1. **侧方位 + 倒车入位（左侧/右侧）**
   - 期望：`后退 4/5 L_open → 第一次自转 → 后退 1.1 × raw_at_stop → 第二次自转 → 完成`
2. **侧方位 + 前进入位（左侧/右侧）**
   - 期望：`前进 1/2 L_open → 第一次自转 → 前进 1.1 × raw_at_stop → 第二次自转 → 完成`
3. **垂直 + 倒车入位（左侧/右侧）**
   - 期望：`后退 9/10 L_open → 自转 → 后退 L_depth − 6 cm → 完成`
4. **垂直 + 前进入位（左侧/右侧）**
   - 期望：`前进 3/4 L_open → 自转 → 前进 min(L_depth − 18 cm, 40 cm) → 完成`
5. **用户中断**
   - 搜索阶段按 `KEY_UP`：停车并返回方向选择
   - 泊车阶段按 `KEY_UP`：立即终止、关闭蜂鸣器并返回方向选择
   - 等待确认阶段当前只响应 `KEY1`

## 10. 与旧版文档的差异

- 旧版文档使用 `Reverse_Start()`、`Reverse_Update()`、`Reverse_Abort()`、`REV_STAGE_*` 和 `CAR_MODE_REVERSING`；当前代码已统一为 `Parking_Start()`、`Parking_Update()`、`Parking_Abort()`、`PARK_STAGE_*` 和 `CAR_MODE_PARKING`。
- 旧版只描述平行倒车入位；当前代码增加了垂直车位分支和“前往后 + 前进入位”参数支路。
- 旧版把 `d1 = 4 × L_slot / 5` 写成所有模式的通用公式；当前代码中该公式只适用于平行 + 倒车入位，其他模式分别使用 1/2、9/10、3/4。
- 旧版使用 `Motion_Forward10()` / `Motion_Backward10()`；当前代码使用 `Motion_ParkForward()` / `Motion_ParkBackward()`，搜索阶段另有 `Motion_SearchForward()` / `Motion_SearchBackward()`。
