# 倒车算法实施（对接 `bishe` 当前工程）

## 1. 文档目标
本文档说明当前 `bishe` 工程中“搜寻车位 -> 发现车位 -> 确认 -> 自动倒车入位”的实现方式，并与 [main.c](../firmware/Core/Src/main.c) 保持一致。

约束：

- 不修改 `motor.h` 对外公共接口
- 动作控制仍在 `main.c` 内通过 `Motor_SetSpeedPercent(...)` 和 `Motor_StopAll(...)` 组合完成
- 倒车流程通过 `CAR_MODE_REVERSING` 下的子状态机执行
- 当前默认关闭倒车避障与蜂鸣器提示，以优先保证倒库动作精度

---

## 2. 当前工程映射关系

### 2.1 已有输入变量

- `g_last_slot_length_cm`
  搜索阶段根据前进速度和开放区时间估算得到的车位长度
- `g_slot_stop_raw_cm`
  识别到车位并停车时记录的原始超声距离，作为第二段倒车距离
- `g_search_dir`
  当前车位方向，取值为 `SEARCH_DIR_LEFT` 或 `SEARCH_DIR_RIGHT`

### 2.2 已有入口

- 入口条件：
  `CAR_MODE_WAIT_KEY1_CONFIRM` 状态下按下 `KEY1`
- 入口动作：
  调用 `Reverse_Start()`，然后切入 `CAR_MODE_REVERSING`

### 2.3 已有电机接口

当前工程继续使用：

- `Motor_SetSpeedPercent(MotorId_t id, int16_t speed_percent)`
- `Motor_StopAll(MotorStopMode_t mode)`

`main.c` 中封装的动作函数为：

- `Motion_Forward10()`
- `Motion_Backward10()`
- `Motion_SpinLeft20()`
- `Motion_SpinRight20()`
- `Motion_StopBrake()`

### 2.4 已有蜂鸣器接口

当前工程已在 `PF8` 接入板载蜂鸣器，相关函数为：

- `Buzzer_Set(uint8_t on)`
- `Buzzer_Stop(void)`
- `ReverseBuzzer_Update(...)`

蜂鸣器仅作为倒车安全提示使用，不参与控制判定。当前默认通过宏关闭。

## 3. 当前版本参数

以下速度与转向时间参数基于 `2026-03-19` 实车测试结果更新。
当前参数表默认以“后往前寻位（R2F search + reverse park）”为基准。
“前往后寻位（F2R search + forward park）”目前已单独修正为：第一段 `d1 = L_slot / 2`，第一次自转 `1464 ms`，第二次自转 `1563 ms`；其余参数暂沿用当前通用值。

### 3.1 运动标定参数

- 前进速度：`10%`，等效 `18.46 cm/s`
- 后退速度：`10%`，等效 `18.46 cm/s`
- 自转速度：`15%`
- 车长：`31.0 cm`

### 3.2 搜索车位参数

- 侧向偏移修正：`SLOT_SENSOR_OFFSET_CM = 9.0 cm`
- 开放区宽度阈值：`SLOT_WIDTH_THRESHOLD_CM = 22.0 cm`
- 车位附加余量：`SLOT_EXTRA_MARGIN_CM = 6.0 cm`
- 最小车位长度：
  `SLOT_MIN_LENGTH_CM = CAR_LENGTH_CM + SLOT_EXTRA_MARGIN_CM = 37.0 cm`
- 搜索判定时间阈值：
  `SLOT_TIME_THRESHOLD_S = SLOT_MIN_LENGTH_CM / 18.46 ≈ 2.004 s`

### 3.3 倒车参数

- 直线积分速度：`V_MOVE_CM_S = 18.46 cm/s`
- 后向防碰撞阈值：`D_SAFE_CM = 5.0 cm`
- 第一段自转时间：`T_TURN_AWAY_90_MS = 1301 ms`
- 第二段自转时间：`T_TURN_TO_SLOT_90_MS = 1544 ms`

### 3.4 蜂鸣器提示参数

- 近距离加速阈值：`REVERSE_BEEP_NEAR_CM = 12.0 cm`
- 常规鸣叫导通时间：`120 ms`
- 常规鸣叫关闭时间：`280 ms`
- 近距离鸣叫导通时间：`80 ms`
- 近距离鸣叫关闭时间：`120 ms`

### 3.5 当前默认开关状态

- `REVERSE_OBSTACLE_AVOID_ENABLE = 0`
- `REVERSE_BEEP_ENABLE = 0`

### 3.6 倒车距离公式

- 第一段倒车距离：
`d1 = 4 * g_last_slot_length_cm / 5`
- 第二段倒车距离：
  `d2 = 1.1 * g_slot_stop_raw_cm`

## 4. 搜索车位算法

### 4.1 判定流程

1. 超声读取原始距离 `d_raw`
2. 计算侧向距离 `d_side = d_raw - 9.0`
3. 若 `d_side > 22.0 cm`，则认为进入开放区并开始计时
4. 若之后 `d_side <= 22.0 cm`，则结束开放区计时，得到 `t_open`
5. 用 `L_slot = 18.46 * t_open` 估算车位长度
6. 若 `t_open >= 2.004 s`，则认定找到了可停入车位，并停车等待 `KEY1` 确认

### 4.2 识别结果

识别成功后记录：

- `g_last_open_time_s`
- `g_last_slot_length_cm`
- `g_slot_stop_raw_cm`
- `g_slot_stop_side_cm`

## 5. 倒车防碰撞与蜂鸣提示规则

说明：以下逻辑是代码中保留的功能结构，但在当前默认配置下处于关闭状态。

### 5.1 启动前动作

- 将舵机恢复到 `SERVO_CENTER_ANGLE`，作为后向测距姿态
- 通过 `MeasureRearDistanceCm()` 可进行后向测距
- 复位蜂鸣器状态，确保从关闭状态进入倒车

### 5.2 防碰撞触发逻辑

仅对两个“后退阶段”生效，自转阶段不做暂停控制：

- 若 `d_rear < 5.0 cm`
  立即执行 `Motion_StopBrake()`，并置 `g_reverse_paused_by_obstacle = 1`
- 若 `d_rear > 5.0 cm`
  恢复 `Motion_Backward10()`，并置 `g_reverse_paused_by_obstacle = 0`
- 若 `d_rear == 5.0 cm`
  保持当前状态，不切换

### 5.3 蜂鸣器提示逻辑

同样仅在两个“后退阶段”启用：

- 正常后退时周期性间断鸣叫
- 若 `d_rear <= 12.0 cm`
  提高蜂鸣频率，提示车辆更接近后方障碍
- 若已触发防碰撞暂停
  蜂鸣器持续导通，作为紧急报警
- 在自转、完成或中止倒车时
  关闭蜂鸣器

### 5.4 位移积分规则

只有在“后退电机实际运行且未因障碍暂停”时才积分：

```c
moved += 18.46f * dt_s;
```

## 6. 倒车子状态机

### 6.1 状态定义

```c
typedef enum
{
    REV_STAGE_INIT = 0,
    REV_STAGE_HALF_SLOT_BACKWARD,
    REV_STAGE_TURN_AWAY_90,
    REV_STAGE_G_STOP_BACKWARD,
    REV_STAGE_TURN_TO_SLOT_90,
    REV_STAGE_DONE,
    REV_STAGE_ABORT
} ReverseStage_t;
```

### 6.2 左右车位转向映射

- 左侧车位 `SEARCH_DIR_LEFT`
  - 第一转：右自转 `1301 ms`
  - 第二转：左自转 `1544 ms`
- 右侧车位 `SEARCH_DIR_RIGHT`
  - 第一转：左自转 `1301 ms`
  - 第二转：右自转 `1544 ms`

### 6.3 执行流程

1. `REV_STAGE_INIT`
   - 检查 `g_last_slot_length_cm > 0` 且 `g_slot_stop_raw_cm > 0`
- 计算 `target1 = 4 * L_slot / 5`
- 计算 `target2 = 1.1 * raw_at_stop`
   - 清零积分和计时器

2. `REV_STAGE_HALF_SLOT_BACKWARD`
   - 后退
   - 累计第一段后退距离
   - 当 `moved1 >= target1` 时进入第一转

3. `REV_STAGE_TURN_AWAY_90`
   - 按车位方向做第一段反向自转
   - 自转 `1301 ms`
   - 完成后进入第二段后退

4. `REV_STAGE_G_STOP_BACKWARD`
   - 继续后退
   - 累计第二段后退距离
   - 当 `moved2 >= target2` 时进入第二转

5. `REV_STAGE_TURN_TO_SLOT_90`
   - 向车位方向执行第二次自转
   - 自转 `1544 ms`
   - 完成后进入 `REV_STAGE_DONE`

6. `REV_STAGE_DONE`
   - 刹停
   - 返回 `CAR_MODE_WAIT_DIRECTION`

7. `REV_STAGE_ABORT`
   - 刹停
   - 返回 `CAR_MODE_WAIT_DIRECTION`

## 7. 当前实现要点

### 7.1 `Reverse_Start()`

- 对倒车数据做合法性检查
- 舵机回中
- 设置：
- `g_rev_target1_cm = 4 * g_last_slot_length_cm / 5`
- `g_rev_target2_cm = 1.1 * g_slot_stop_raw_cm`
- 清零累计距离、暂停标志和蜂鸣器状态
- 进入 `REV_STAGE_HALF_SLOT_BACKWARD`

### 7.2 `Reverse_Update()`

- 每次循环计算 `dt_s`
- 根据当前子状态执行：
  - 后退阶段：位移积分
  - 自转阶段：按时间控制结束
- 允许 `KEY_UP` 在任意倒车阶段触发 `Reverse_Abort("User stop")`

### 7.3 `ReverseBuzzer_Update(...)`

- 负责倒车阶段的非阻塞蜂鸣控制
- 不改变倒车状态机，仅作为状态反馈输出
- 可根据后向距离和暂停状态自动切换鸣叫节奏
- 当前默认未启用
